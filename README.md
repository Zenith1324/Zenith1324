# Русскiя Шахматы

Шахматное приложение в русском императорском стиле: игра против движка
**Stockfish 18**, полный разбор партии, часы, игра с живым соперником по сети
и музыка **А. Н. Скрябина**.

Интерфейс целиком на русском языке — в дореформенной орфографии, ради стиля.

---

## Как запустить

### На macOS — двойной щелчок

Дважды щёлкните по файлу **`ЗАПУСК.command`**. Откроется браузер с игрой.

Если macOS откажется запускать файл («неопознанный разработчик»), щёлкните по
нему правой кнопкой → **Открыть** → **Открыть**.

### Вручную (любая система)

```bash
cd путь/к/папке
python3 -m http.server 8173
```

затем откройте <http://localhost:8173/index.html>.

### Просто открыть `index.html`

Двойной щелчок по `index.html` тоже работает — играть можно сразу. Но
**Stockfish при этом не загрузится**: браузеры не разрешают запускать Web
Worker и WASM с `file://`. Включится встроенный движок, он заметно слабее.
Приложение само покажет наверху страницы готовую команду для Терминала —
её достаточно скопировать и вставить.

### Если `ЗАПУСК.command` не открывается

Так бывает после скачивания архива: macOS помечает файлы «карантином», а zip
теряет право на запуск. Лечится одной строкой в Терминале — вставьте её,
находясь в папке приложения:

```bash
xattr -cr . && chmod +x *.command && ./ЗАПУСК.command
```

Либо вообще обойдитесь без него:

```bash
cd ~/Desktop/Zenith1324-claude-russian-chess-app-hx4dty
python3 -m http.server 8173
```

и откройте <http://localhost:8173/index.html>. Пока окно Терминала открыто,
игра работает; чтобы остановить сервер — Control+C.

## Что внутри

### Игра против машины

Шесть уровней с настоящей разницей в силе (Stockfish с ограничением рейтинга):

| Уровень | Примерный рейтинг |
|---|---|
| Новичок | ≈800 |
| Любитель | ≈1200 |
| Клубный игрок | ≈1600 |
| Кандидат в мастера | ≈1900 |
| Гроссмейстер | ≈2400 |
| Чемпион мира | ≈2850 (без ограничений) |

### Часы

`1+0`, `3+0`, `3+2`, `5+0`, `5+3`, `10+0`, `10+5` и режим без часов.
Добавление времени (инкремент) начисляется после каждого хода, при падении
флага партия завершается.

### Разбор партии

Каждый ход получает оценку движка и категорию — как на шахматных сайтах:

| Знак | Категория |
|---|---|
| ‼ | Блестящий (жертва, остающаяся сильнейшим ходом) |
| ! | Отличный (единственный ход, удерживающий позицию) |
| ★ | Лучший ход |
| ✓ | Хороший |
| ?! | Неточность |
| ? | Ошибка |
| ?? | Зевок |

Кнопка **«Разобрать партію»** прогоняет всю партию через движок на большой
глубине. Точность каждой стороны считается по изменению шансов на победу.

По партии можно ходить: щелчком по любому ходу в записи, кнопками
`⏮ ◀ ▶ ⏭`, стрелками `←` `→` и клавишами `Home` / `End`. Зелёная стрелка на
доске показывает, что следовало сыграть.

### Игра с живым соперником

Прямое соединение браузер↔браузер (WebRTC), **без сервера**. Во вкладке
**«По сѣти»** мастер ведёт по шагам — на экране всегда видно только то,
что нужно сделать сейчас.

Сначала выбираете, кто вы в этой партии:

**«Я приглашаю»**
1. Появляется код приглашения — отправьте его другу (мессенджер, почта).
2. Друг пришлёт код ответа — вставьте его и нажмите «Соединиться».

**«Меня пригласили»**
1. Вставьте код приглашения, нажмите «Продолжить».
2. Появится ваш код ответа — отправьте его обратно и ждите.

Дальше доска, часы и ходы синхронизируются сами. Нужен доступ в интернет
(для обхода NAT используются публичные STUN-серверы). Партии по сети не
влияют на рейтинг.

### Рейтинг

Рейтинг Эло, который хранится в браузере. Победа над более сильным соперником
приносит больше очков, поражение от него отнимает меньше, чем поражение от
слабого. Разряды — по образцу отечественной спортивной классификации,
от III разряда до гроссмейстера.

### Музыка

**Самый верный способ — свои записи.** В панели «Музыка и звукъ» нажмите
**«Выбрать свои записи…»** и укажите свои файлы: например Симфонию № 3
(«Божественная поэма»), часть III, или «Поэму экстаза». Файлы хранятся
в браузере и переживают перезапуск. Первый файл идёт на победу, второй на
поражение, третий на ничью; можно назвать их `victory`, `defeat`, `draw` —
тогда они разложатся точно.

Если своих записей нет, приложение ищет звук само:

1. Файлы в `assets/audio/` — их кладёт **`МУЗЫКА.command`** (двойной щелчок).
2. Викисклад — записи со свободной лицензией, прямо из браузера.
3. Оркестровый синтезатор — работает всегда, но это не запись.

**Отбор строгий:** запись принимается, только если в её названии есть и
фамилия Скрябина, и признак нужного произведения. Иначе она отвергается —
лучше честный синтезатор, чем чужая музыка под видом Скрябина. Под каждым
случаем в панели написано, что именно там стоит и откуда оно взято.

Что играет:

* **Победа** — Симфония № 3 «Божественная поэма», соч. 43, ч. III
  («Божественная игра»); запасной вариант — «Поэма экстаза», соч. 54
* **Поражение** — Симфония № 3, ч. I («Борьба»); запасной вариант —
  Этюд ре-диез минор, соч. 8 № 12
* **Ничья** — Прелюдия соч. 11; запасной вариант — «Мечты», соч. 24
* **Блестящий ход** — восходящий взлёт (синтез)
* **Зевок** — «прометеев» (мистический) аккорд Скрябина (синтез)

Синтезатор моделирует оркестровые группы: струнные из девяти расстроенных
голосов со смещёнными атаками, медь с раскрывающимся фильтром, литавры,
деревянные духовые и зальную реверберацию.

### Управление фигурами

Фигуры можно **перетаскивать мышью** или **ходить щелчками**: щелчок по фигуре
подсвечивает доступные поля, щелчок по полю делает ход.

## Фон — полотна И. И. Шишкина

Фоном идут настоящие картины Шишкина (1832–1898, общественное достояние).
Порядок поиска:

1. **Локальный файл** `assets/paintings/shishkin.jpg` — положите свой или
   запустите **`КАРТИНЫ.command`** (двойной щелчок), который скачает
   несколько известных полотен с Викисклада.
2. **Викисклад** — приложение запрашивает категорию «Paintings by Ivan
   Shishkin» прямо из браузера и ставит случайное полотно. Список
   кэшируется на неделю; кнопка «другое полотно» в подвале меняет картину.
3. **Рисованный пейзаж** `assets/shishkin-forest.svg` — если сети нет.

Название текущего полотна показано в подвале страницы.

## Устройство кода

| Файл | Назначение |
|---|---|
| `js/chess-engine.js` | Правила игры, генерация ходов, FEN/UCI |
| `js/engine-native.js` | Встроенный движок (запасной) |
| `js/engine-manager.js` | Единый интерфейс к Stockfish или встроенному движку |
| `js/analysis.js` | Классификация ходов и точность |
| `js/rating.js` | Рейтинг Эло |
| `js/clock.js` | Часы |
| `js/music.js` | Оркестровый синтезатор (запасной звук) |
| `js/audio-library.js` | Фонотека: свои записи, файлы, Викисклад |
| `js/gallery.js` | Полотна Шишкина на заднем плане |
| `js/multiplayer.js` | Игра по сети (WebRTC) |
| `js/app.js` | Интерфейс и связывание всего вместе |

Сборка не нужна: обычные файлы, никаких зависимостей для установки.

Корректность генерации ходов проверена тестом **perft** на начальной позиции
и на позиции «Kiwipete» (рокировки, взятие на проходе, связки).
